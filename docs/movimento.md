# Movimento

Animação serve para dar retorno, não para chamar atenção. Nada passa de 300ms.

<!-- constela:movimento -->

- Prefira transição CSS. Animação com biblioteca só em troca de página e reordenação de lista.
- Entrada: fade com subida de 8px em 200ms. Saída: só fade, em 150ms.
- Respeite `prefers-reduced-motion`: com ele ativo, troque deslocamentos por fade ou remova a animação.
