# Contribuindo

O guia completo está na documentação: https://constela.novah.care/contribuindo.html

Resumo:

1. Abra uma issue explicando o problema.
2. Mude `tokens/tokens.json` (ou `src/`) e a documentação em `docs/`.
3. Rode `npm run check`.
4. Registre a mudança no `CHANGELOG.md`, em "Não lançado".
5. Abra o pull request.

Não inclua nada interno da Novah Care: nomes de sistemas, endereços de ambientes, dados de clientes ou de colaboradores.
